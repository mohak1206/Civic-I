## What Could Not Be Tested
1. **Docker Execution:** `docker` is not installed on this Windows host system; commands were run natively in the Windows environment.
2. **Cold-load Live Text Throughput:** While `GET /api/tags` confirmed all three models are installed locally, sequential cold-model weights loading on host CPU took longer than 30s, triggering client timeout. Deterministic template fallback was verified.
3. **Live Vision Review on Real Street Photos:** Deferred until licensed municipal sample images are placed in `assets/`.
