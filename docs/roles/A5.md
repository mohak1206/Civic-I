# Role Specification: A5 - Citizen App and Public Map

## Identity & Scope
- **ID:** A5
- **Role Title:** Citizen App & Public Map Frontend Engineer
- **Active Branch:** `a5/design-system`
- **Ownership Folders:**
  - `build/web/src/citizen/`: Citizen flows (Landing page, 4-step reporting wizard, tracking portal)
  - `build/web/src/map/`: OpenStreetMap + Leaflet location picking and status visualization
  - `build/web/src/shared-ui/`: Reusable design system primitives (Button, Card, Badge, Stepper, CornerFrame, SectionLabel, Navbar, Footer)
- **Test Ownership:**
  - `test/web/`: Unit and component validation tests

## Core Responsibilities
1. **Visual Design System:**
   - Palette: Warm off-white background (`#F5F3EE`), dark navy panels (`#1B2536`), accent orange (`#E8501F`), accent blue (`#3B7DD8`), gold (`#D4960F`).
   - Typography: Space Grotesk (headings and small labels), serif (Source Serif 4 / Spectral) for body prose.
   - Motif: Square corners (0-2px), 1px dark borders, L-shaped corner brackets (`CornerFrame`).
   - Icons: `lucide-react`. Zero paid SDKs, zero Google Cloud / Firebase dependencies.
2. **Citizen User Interface:**
   - Landing page at `/`: Hero with AI suggestion badge, platform impact band (with DEMO tags for seed data), 4-step "How It Works" diagram, built with open tools grid, privacy note, and CTA.
   - Component Showcase at `/dev/components`: Complete visual gallery of all shared UI primitives.
   - 4-Step Report Wizard at `/report`:
     - Step 1: Capture (Drag & drop, camera input, file upload with client-side validation against `src/citizen/config.ts`, face/license plate warning).
     - Step 2: Analyze (Service call to `src/citizen/api/reports.ts` supporting `VITE_USE_MOCK`, bounding box display, category selector for `pothole` and `garbage` only, AI suggestion advisory label).
     - Step 3: Confirm (Leaflet + OpenStreetMap pin dropping, description with char limit, summary).
     - Step 4: Submit (Multipart payload to `POST /reports`, reference code copy, disclaimer that nothing is assigned yet).
   - Report Tracking at `/track` and `/track/:ref`:
     - Reference number search.
     - Vertical timeline mapping the 13 report lifecycle statuses.
     - Reopen button for resolved issues.
3. **Project Rule Compliance (`PROJECT_RULES.md`):**
   - No fabricated model accuracy or municipal claims.
   - Clear labeling: "AI output is a suggestion. An official reviews it."
   - Demo/placeholder badges on seed metrics and unassigned workflows.
   - Absolute privacy: Reporter personal details are never public.
   - Mobile-first responsive layouts tested at 375px, 768px, and 1280px.
