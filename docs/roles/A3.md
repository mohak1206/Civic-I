# Role Specification: A3 — Ollama Multi-Model Integration & Pipeline

## Identity & Scope
- **ID:** A3
- **Role Title:** Agent Engineer — LLM/VLM Integration & Pipeline
- **Active Branch:** `a3-ollama-multimodel`
- **Ownership Folders:**
  - `build/backend/app/services/llm/`: Shared Ollama client, model router, draft generator, output guard, templates, health check
  - `build/backend/app/services/vision/`: Visual reviewer (gemma3), image preparation, stub reviewer
  - `build/backend/app/pipeline/`: Pipeline coordinator (sequential step orchestrator)
- **Test Ownership:**
  - `test/backend/a3/`: All unit tests, integration tests, and benchmark scripts

## Core Responsibilities
1. **Shared Ollama Client:** httpx-based client for Ollama REST API (POST /api/chat, GET /api/tags). No LangChain/LangGraph.
2. **Model Router:** Route tasks to vision (gemma3:latest), decision (qwen3.5:2b), or fallback (llama3.2:3b) with graceful degradation.
3. **Vision Review:** Advisory-only VLM review of YOLO results using gemma3. May escalate but never override YOLO.
4. **Decision/Advisory Drafting:** Inspection-request drafts with qwen, llama fallback, and deterministic template as final fallback.
5. **Pipeline Coordinator:** Sequential orchestration of YOLO → vision review → dedup → priority → authority → advisory steps.
6. **Privacy:** Never send reporter PII or raw citizen text to any model.
7. **Project Rules Compliance:** No fabricated metrics, AI output labelled as suggestion, PLACEHOLDER/DEMO data clearly marked.
