# Civic-I

Civic-I is an AI-assisted civic issue reporting platform for Palghar City, Maharashtra, designed to empower citizens to report local civic issues (potholes and garbage), while providing municipal teams with structured triage, verification workflows, and resolution tracking.

## Folder Map

- `build/`: Application source code (backend, web frontend, ML services, and seed scripts)
- `test/`: Test suites (backend, pipeline, spatial, web, eval, e2e, ml, and CI)
- `docs/`: Documents (roles, architecture decisions, and status updates)
- `assets/`: Small images and static assets
- `promt.txt`: Prompt log tracking prompts and outcomes

MVP in development. No model accuracy claimed until measured.
